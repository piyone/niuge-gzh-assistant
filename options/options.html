默认主题

在公众号编辑页的「排版」标签(② 主题美化区)里也可以随时切换并预览。

排版规则

代码块内永远不会被修改。

自定义违禁词

内置词库已覆盖常见广告法极限词与高风险承诺用语,这里补充你所在行业的专属词。

AI 模型配置

支持所有 OpenAI 兼容接口:选服务商自动填地址与常用模型,Key 按服务商分别记忆;也可手改任意字段。测试连接会真实调用一次接口验证 Key 与模型。⚠️ 思维链模型(如 glm-4.7-flash)会消耗推理 token 导致校对结果被截断,建议用非推理模型。密钥仅存本地浏览器,请勿分享装好密钥的插件目录。

配置备份

使用说明

  1. 打开 mp.weixin.qq.com → 图文消息 → 新建图文(写文章)。
  2. 页面右侧出现「牛」字悬浮球,点击展开面板。
  3. 导入:粘贴 Markdown → 预览 → 「注入编辑器」或「复制富文本」手动粘贴。
  4. 排版:三个区块一站式——①一键规范(中英空格/全角标点/省略号/空行/外链脚注)②主题美化(6 套主题+字号行距+手机预览)③防丢稿(快照历史)。每次操作前自动存快照。
  5. 检查:发布前跑一遍违禁词 / 外链 / 图片域名 / 段落节奏检查。
  6. AI 校对:调用 AI 检查错别字、语句不通顺、标点误用,逐条一键应用。
  7. 同步:一键把文章写入知乎专栏 / 掘金草稿箱(用浏览器已登录的账号;发布到平台仍需手动确认)。
  8. 预览:375px 手机宽度还原读者视角。

如果「注入编辑器」在个别浏览器版本失效,用「复制富文本」后到编辑器里 Ctrl/Cmd + V,效果完全一致。
