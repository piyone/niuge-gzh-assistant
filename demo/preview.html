雅蓝 · 微信官方蓝,稳重大方

为什么你的公众号排版总是差一口气?

凌晨一点,你终于改完稿子。粘贴进公众号后台,图片歪了、代码糊了、标题灰了——你开始逐段手动调格式,一调就是一个小时。

这不是文笔问题,是工作流问题。

好的排版不是好看,而是让读者以最小的成本读完。

三个被忽视的细节

1. 中英文之间要有空格

「用 CSS 实现动画」和「用 CSS 实现动画」,在手机上的阅读舒适度完全不同。人眼对词组边界的识别依赖空隙,这叫「盘古之白」。

2. 外链要让读者「死心」

公众号正文里,除微信域名的链接全都点不开。与其放一个蓝色的死链接,不如自动转成文末的引用链接,正文里只留 [1] 标记。

3. 发布前要有一道「安检」

广告法极限词(最低价、第一名、100%)是限流和投诉的重灾区;外部图片域名随时可能被防盗链拦截。这些都应该在点「群发」之前查完。

代码也要体面

const article = await mopai.render(markdown, {
  theme: 'elegant',      // 六套主题
  rules: { pad: true },  // 盘古之白
});
await mopai.inject(article.html); // 直接进入公众号编辑器

行内代码 npm install 也一样清爽。
