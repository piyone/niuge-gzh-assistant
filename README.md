## 📦 安装(Chrome / Edge / Arc 等 Chromium 浏览器)

1. 下载本仓库:页面右上角 **Code → Download ZIP** 解压,或 `git clone`
2. 打开 `chrome://extensions`(Edge 为 `edge://extensions`)
3. 右上角开启「**开发者模式**」
4. 点「**加载已解压的扩展程序**」,选择本仓库目录
5. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com/) → 新建图文,右侧出现「牛」字悬浮球即安装成功

> **💡 提示**
> - 仅支持 Chromium 内核浏览器(MV3 的 DNR 会话规则用法不同,Firefox / Safari 暂不支持)
> - **更新版本**:覆盖目录后回到扩展管理页,点插件卡片上的「刷新」按钮
> - **卸载**:扩展管理页点「移除」;所有数据只存本机,卸载即清除
> - 浏览器大版本升级可能提示权限变更,属正常现象

## 🚀 功能详解

### 🎨 排版(三区块一站式)

- **一键规范**:中英空格、全角标点、省略号标准化(`。。。/...` → `……`)、连续标点收敛、压缩空行、外链脚注化——每一项都可单独执行
- **主题美化**:6 套预设主题(雅蓝/科技蓝/暖橙/青竹/极简黑白/樱粉)+ **自定义主题**(8 色取色器 + 标题风格);字号/行距/字间距/图片圆角/图片阴影/**两侧边距**滑杆实时预览
- **防丢稿**:恢复上次快照 + 快照历史时间线

### 🤖 AI 写 / 检查

- **写文章**:选题 + 风格(干货/观点/故事/清单)+ 目标读者 → 700~900 字初稿;「继续写」追加段落;插入编辑器(改前自动存快照)
- **标题**:5 种风格候选(悬念好奇/数字干货/痛点共鸣/观点态度/场景故事),≤30 字避开极限词,一键「采用」
- **摘要**:60~110 字会话卡片摘要,一键填入摘要框
- **AI 校对**:错别字/语病/标点逐条应用,误报抑制(型号/口语不算错)
- **规则体检**:违禁词 6 类扫描、外链、图片防盗链域名、标题层级、篇幅预警等 11 项本地即时检查
- **AI 文章检测**:一键跳转腾讯朱雀检测 AI 痕迹

### 🖼 图片采集(任意网页 → 公众号素材库)

在**任何网页**看到好图,右键直接进公众号素材库,不用先下载再手动上传:

1. 右键网页图片 → **「采集图片到公众号素材库」**
2. 多个公众号同时登录时,二级菜单直接列出各账号,**点谁传谁**
3. 页面右上角出现进度圆圈 → 成功显示 ✅ 自动消失;失败给出具体原因
4. 自动处理:**防盗链**(Referer 伪装)、**格式归一化**(webp/avif 自动转 png)、临时 DNR 规则、页面中继同源上传

> 实现:复用浏览器登录态调用公众号素材库接口(方案对齐 wechatsync v2),全程由你的浏览器直连,无中转服务器。需要扩展拥有所有网站权限(仅用于抓取你主动右键的图片)。

## ⌨️ 典型工作流

```text
方式一(AI 代写)  AI写 选题 → 初稿 → 继续写 → 插入编辑器
                 → AI 标题采用 / 摘要填入
                 → 排版:一键规范 + 套主题
                 → 检查:AI 校对 + 规则体检
                 → 同步:知乎/掘金等一键写草稿
                 → 预览:手机视角过一遍 → 群发

方式二(自己写)   编辑器写完(或贴 Markdown)→ 从「排版」开始走同一流程
```

> 🛟 **任何一步改坏了**:「排版 → 恢复上次快照」一键回滚;每 90 秒还会自动留档一份历史快照(最多 10 份,内容有变化才存),「快照历史」可按时间点恢复。

## 🤖 AI 模型配置

- **9 个服务商预设一键切换**:aitools.cfd / DeepSeek / 智谱 / Kimi / 通义千问 / 硅基流动 / OpenRouter / Ollama 本地 / 自定义 OpenAI 兼容
- **Key 按服务商分别记忆**,密码框 + 一键显隐;全部仅存本机 `chrome.storage.local`,不上云
- **测试连接**:真实调用验证 Key 与模型;401/404/429 给出针对性提示;自动检测 thinking 推理模型并警告换模型
- 未配置时 AI 页面显示引导横幅,设置页修改**实时同步**到面板,无需刷新

**AI 校对小知识**

- 文章按段落分块(≤3200 字/块)自动校对,429 限流按 `Retry-After` 等待
- 默认模型 `zhipu/glm-4-flash`(非推理型,JSON 输出稳定);⚠️ 不要换 `glm-4.7-flash` 等 thinking 模型——推理 token 会吃满 max_tokens 导致结果截断
- 「应用」= 精确字符串替换,改前自动存快照

## 🛠 技术要点

- **Manifest V3** 无构建步骤,纯静态文件;后台 Service Worker
- 渲染管线:`marked`(GFM)→ `DOMPurify` 消毒 → 中文排版规范 → `highlight.js` 高亮内联化 → 主题样式全量写入 `style` 属性(公众号保存后唯一存活的样式方式)
- 编辑器注入:模拟键盘全选 → 等待 ProseMirror 选区同步 → 合成 paste → 长度比对防重复 → 自动撤销重试
- 图片采集:页面中继(`chrome.scripting`)同源请求绕过环境校验;OffscreenCanvas 格式归一化;DNR 临时 Referer 规则破防盗链
- AI 请求经后台 SW 代理规避 CORS;平台同步复用浏览器 Cookie,受限请求头经 `declarativeNetRequest` 会话规则注入
- 引擎函数全部纯函数化(`engine/`),无 chrome 依赖,jsdom 可测

## ❓ FAQ

<details>
<summary><b>API Key 安全吗?</b></summary>

Key 仅存本机 `chrome.storage.local`,不上传任何服务器;AI 请求由浏览器后台直连你选择的服务商。不要分享配置过 Key 的浏览器配置文件。

</details>

<details>
<summary><b>同步/采集为什么需要这么多站点权限?</b></summary>

同步 = 用你浏览器里已登录的平台账号调用该平台自己的草稿接口;图片采集需要在任意网页抓取你右键的图片。所有请求都由你的浏览器直接发出,本项目无任何中转服务器。

</details>

<details>
<summary><b>图片采集失败怎么办?</b></summary>

失败提示会给出具体原因:未登录公众号、登录态过期(重新登录即可)、图片被防盗链(插件已自动处理大部分)、素材库为空(需先手动上传过一张图)等。

</details>

<details>
<summary><b>同步失败怎么办?</b></summary>

平台改版会导致接口失效,面板会逐平台显示失败原因;任何时候都可以用「复制 Markdown / 复制富文本」手动兜底。

</details>

<details>
<summary><b>AI 为什么提示模型输出异常?</b></summary>

优先使用非推理模型(默认 `glm-4-flash`);thinking 类推理模型的思考 token 会吃满 max_tokens 导致 JSON 截断,「测试连接」会主动检测并提醒。

</details>
